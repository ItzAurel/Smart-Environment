## 🚀 Pengenalan Projek
Halo gusy! Smart Environment adalah sebuah prototype berbasis ESP32 yang
menggunakan berbagai sensor untuk memantau kondisi lingkungan baik di dalam ruangan
maupun luar ruangan secara **real-time**.
|| Sistem ini dapat memantau
* Suhu
* Kelembapan
* Kualitas Udara
* Intensitas Cahaya
* Kelembapan Tanah
* Ketinggian Air
* Mendeteksi Indikasi Pergerakan.

Data sensor akan ditampilkan melalui OLED dan dapat dipantau melalui aplikasi Blynk,
sementara LED dan buzzer yang akan memberikan peringatan jika beberapa sensor tertentu mendeteksi suatu hal.
